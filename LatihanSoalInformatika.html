BAGIAN B: SOAL ESAI (5 Soal)
1. Jelaskan 3 komponen utama dalam sistem komputer (Hardware, Software, dan Brainware) beserta peran dan hubungan saling ketergantungannya!
2. Jelaskan perbedaan antara Command Line Interface (CLI) dan Graphical User Interface (GUI) dalam interaksi manusia dan komputer, beserta kelebihan dan kekurangan masing-masing!
3. Sebutkan dan jelaskan 4 fungsi utama sistem operasi dalam mengelola sumber daya sistem komputer!
4. Jelaskan secara berurutan siklus eksekusi instruksi CPU (Fetch, Decode, Execute, dan Store)!
5. Sebutkan dan jelaskan peran dari 3 komponen utama di dalam CPU, yaitu Control Unit (CU), Arithmetic Logic Unit (ALU), dan Register!
